### 🌟 مميزات المشروع
1. **عرض تفاعلي هجين:**
   - **وضع صفحة الويب المتصلة (Continuous Landing Page):** تصفح أكاديمي سلس ومريح مع متابعة موقع الشريحة تلقائياً.
   - **وضع منصة العرض التقديمي (16:9 Full HD Presentation Stage):** أبعاد دقيقة 1920 × 1080 متوافقة مع شاشات العرض الذكية وأجهزة العرض (Projectors).

2. **عرض تلقائي ذكي كالبوربوينت (Auto-Play Slideshow):**
   - زر تشغيل/إيقاف تلقائي بضغطة واحدة من الشريط العلوي أو شريط التحكم السفلي.
   - شريط تقدم زمني علوي يوضح الوقت المتبقي لكل شريحة (7 ثوانٍ لقراءة أكاديمية متوازنة).
   - إمكانية التحكم عبر لوحة المفاتيح: مسافة (Space) للتشغيل/الإيقاف، والأسهم للتنقل.

3. **انتقالات 3D سينمائية قوية بين الشرائح (3D Perspective Transitions):**
   - حركات انتقال قوية وديناميكية مدعومة بمكتبة `Framer Motion`.
   - دوران وتجسيم ثلاثي الأبعاد مع تلاشي وعمق حركي فخم يضاهي برامج العروض العالمية (Keynote & PowerPoint).

4. **تصدير وتحميل مباشر بصيغة PowerPoint (.pptx):**
   - زر مخصص لتحميل العرض كملف `.pptx` حقيقي بضغطة واحدة.
   - يتضمن كافة الشرائح الـ 12 مع الهوية الرسمية للجامعة والصور الحقيقية المدمجة.

5. **هوية جامعة العاصمة البصرية:**
   - استخدام درجات الأزرق الملكي الداكن (`#062A5A`) والذهبي الأكاديمي (`#D4AF37`).
   - خطوط عربية حديثة وواضحة (Cairo & IBM Plex Arabic).
   - صور توثيقية حقيقية عالية الجودة لكل شريحة.
